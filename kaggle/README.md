# Kaggle GPU jobs

Phone-verify your Kaggle account, then run these notebooks with a **T4 GPU**.

## Wan 2.2 — moving shots

1. Upload `wan_ti2v_guide.md` contents into a new Kaggle notebook (or follow it cell by cell).
2. Upload keyframes from `outputs/keyframes/` as dataset or input files.
3. Use prompts from `outputs/shots/wan_jobs.json` (generated by `npm run shots`).
4. Draft at lower resolution first; save each `shot_XX.mp4` as you go.
5. Download clips into this repo’s `outputs/shots/`.
6. Re-run `npm run shots` then `npm run assemble` (cache keeps unchanged work).

## ACE-Step 1.5 — score

1. Follow `ace_step_guide.md` on Kaggle/Colab.
2. Generate **3** instrumental candidates from `outputs/music/ace_step_brief.json`.
3. Listen under narration at low volume; pick one; note why in `EXPERIMENTS.md`.
4. Save as `outputs/music/score.wav` (or `.mp3`).

## Quota tips

- Batch overnight; save outputs continuously (sessions time out).
- Prefer Ken Burns fallback over burning the whole week on one broken clip.
- Log GPU minutes in `COSTS.md`.
